# 📊 Async Log Analyzer

A Python learning project for analyzing log files using **asynchronous programming**.

## What is this?

This project is a tool that reads log files (like those from web servers, applications, etc.) and analyzes them asynchronously. The main idea is to **learn** how to use `asyncio` in Python to process large files without blocking the program.

## Learning objectives

- Understand how **asynchronous programming** works in Python
- Practice using `async/await` and `asyncio`
- Learn to read and process files efficiently
- Get familiar with log analysis patterns

## Project goals

The idea is to build an analyzer that will:
- Read log files asynchronously
- Search for specific patterns (errors, IPs, etc.)
- Count lines, errors, and events
- Generate basic reports

## Technologies used

- **Python 3.8+**
- **asyncio** for asynchronous programming
- **aiofiles** for asynchronous file reading

## Project status

🚧 **In development** - This is an educational project to practice asyncio concepts and data analysis.
